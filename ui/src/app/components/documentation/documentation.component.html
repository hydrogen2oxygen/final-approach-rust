DESIGNER MODE - F2

Shortcuts

Locally, use OSM blocks and click two opposite corners of a rectangle (maximum 4 km²). Internet access is required to load OpenStreetMap data. The temporary rectangle disappears after loading; complete street blocks containing buildings become editable drafts. Blocks cut by the rectangle are omitted. Footpaths, service roads, bridges and tunnels do not divide blocks. Results depend on OSM coverage and include mixed residential/commercial blocks. Review the boundaries, then save with CTRL+S. ESC cancels selection or loading. Repeating the selection skips identical polygons.

Block data: © OpenStreetMap contributors, ODbL.

  • CTRL+D Draw a polygon
  • CTRL+E Edit mode
  • CTRL+S Save modifications
  • DEL Delete selected polygon
  • ESC Stop editing
  • F-11 Fullscreen mode
